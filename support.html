Something not working, or an idea to share? Write to us.

mart2010.l@gmail.com

Before you write

The Help page answers the most common questions: setting up an API key, rate limits, hints, accents and “dry” themes.

What to include

  • What happened and what you expected.
  • The puzzle theme, language and difficulty, if the problem concerns a puzzle (for example a wrong clue or answer).
  • Which AI provider you use (never send your API key).
  • Your phone model and Android version.

This is a one-person project, so replies may take a few days.
