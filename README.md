# wordlai-pages

Public static site for the [Wordlai](https://github.com/mart2010/wordlai) Android app, served by GitHub Pages.
Plain HTML/CSS, no build step.

| English | Français |
|---|---|
| `index.html` | `fr/index.html` |
| `help.html` | `fr/aide.html` |
| `privacy.html` | `fr/confidentialite.html` |
| `support.html` | `fr/assistance.html` |

Shared styling: `style.css`. Contact: mart2010.l@gmail.com.

The privacy policy states what the app actually does (no server, no analytics; calls only to the
user's configured LLM providers and freedictionaryapi.com). Update it whenever the app's network
behavior or permissions change.
